# Topmost Fitness Website

A responsive single-page portfolio/booking website for Topmost Fitness.

## Run
Open `index.html` in a browser.

## Customize
Edit the contact details, text, images, and colors in `index.html`.

## Booking
The form generates a WhatsApp booking message to 09027343470. Replace the WhatsApp destination or connect a scheduling platform if desired.

Note: The site currently uses remote Unsplash images as generic fitness placeholders.
